## `README.md`

````markdown
# MD3Agent for macOS

a native swift 6 macos implementation alongside the original kotlin desktop application. the native target uses swiftui, appkit, foundation networking, sqlite, and the security framework. it does not embed a jvm or web renderer.

this migration is **not yet at full functional parity**. the portable core has been compiled and tested on linux. the macos application has not been compiled or run in the implementation environment. do not treat the presence of a release workflow as proof of a working signed release.

## native capabilities

- openai-compatible chat completions, anthropic messages, native ollama chat, and custom openai-compatible endpoints.
- incremental sse and newline-delimited json decoding, indexed tool-call assembly, cancellation, output limits, and provider usage reporting.
- actor-isolated conversation context and sqlite storage for conversations, preferences, memories, and tool run logs.
- credentials in macos keychain, scoped to the exact provider endpoint.
- bounded subprocess output, timeout controls, a minimal child environment, and per-invocation tool approval.
- workspace file operations, lexical memory search, and saved-chat search tools.
- native split-view history/chat/inspector layout, lazy chat rows, inline markdown, fenced code copying, text-file attachments, and settings.
- menu bar controls and a control-option-space global shortcut without accessibility permission.
- a macos notch task panel with elapsed time, hover details, active-tool status, allow-once/deny controls, and stop/open-chat actions.
- semantic system colors mapped to material color roles, system accent, light/dark appearance, and reduced-motion-aware scrolling.

the package builds arm64 directly for apple silicon. this removes the java runtime from the native target, but no memory or performance benchmark has been run. intel builds are configurable; the release workflow currently publishes arm64 only.

## prerequisites

- macos 14 or newer.
- xcode 16 or newer with swift 6 and command line tools selected. ci selects xcode 16.4 on `macos-15`.
- an api endpoint and model id, or ollama running locally with a downloaded model.
- python 3 only if enabling the python execution tool or generating the source bundle.

## build and run

from the repository root on macos:

```bash
swift package resolve
swift build -c debug
swift test --enable-code-coverage
swift run MD3Agent
```

open `Package.swift` in xcode, select the `MD3Agent` scheme and `my mac`, then run. this repository uses an spm executable rather than a checked-in xcode project. xcode's package scheme can also be built from the package directory:

```bash
xcodebuild -list
xcodebuild -scheme MD3Agent -destination 'platform=macOS' -configuration Debug build
```

the `xcodebuild` commands require macos verification; scheme availability is determined by the installed xcode. use `swift build` as the canonical package build.

create a locally ad-hoc-signed app bundle:

```bash
bash scripts/package-macos.sh
open dist/MD3Agent.app
```

the packaging script defaults to arm64 release. set `ARCHITECTURE=x86_64` for intel, `VERSION=1.2.3` for a version, and `SIGNING_IDENTITY` to a developer-id identity for hardened-runtime signing. ad-hoc signing is for local use and does not establish gatekeeper trust.

## configure a provider

open settings, then model provider. select the protocol, enter the complete endpoint url and exact model id, and set the context/output token limits to values supported by that model. enter the api key and choose `save key in keychain`. the field clears after saving. deleting a saved key removes its generic-password item.

| protocol | full endpoint example |
| --- | --- |
| openai | `https://api.openai.com/v1/chat/completions` |
| anthropic | `https://api.anthropic.com/v1/messages` |
| ollama | `http://127.0.0.1:11434/api/chat` |
| custom | the provider's complete openai-compatible chat-completions url |

for local ollama, start its server outside the app, download a model using ollama's documented workflow, choose ollama in settings, and enter the installed model's name. leave the api key empty if the local server does not require one. the app does not install or manage ollama.

remote endpoints require https. plaintext http is accepted only for literal loopback hosts. redirects are rejected to prevent credential forwarding. custom headers exist in the configuration model but do not yet have a dedicated settings editor; do not put credentials in custom headers because preferences are not encrypted.

## permissions and security

every tool has an off, ask, or auto policy. all non-shell tools default to ask; shell and python default to off. ask displays the tool name and complete arguments and requires an allow-once decision. settings are locked during a running response so a run uses one consistent policy snapshot.

`run_command` and `run_python` execute as your user. they can access anything your user can access, including files outside the workspace and the network. **the working directory is not a sandbox.** the distribution deliberately disables app sandbox and does not invent a subprocess entitlement. system execution is incompatible with claiming that arbitrary code is isolated by app sandbox.

child processes receive a minimal environment instead of inherited provider secrets. output capture is bounded and the direct child is terminated on cancellation or timeout. descendant process-tree cleanup is not guaranteed. do not use this implementation for hostile code execution.

workspace file tools reject absolute paths, traversal, and resolved symlinks escaping the workspace. these checks are not a race-proof filesystem sandbox against another process mutating paths concurrently. imported attachments currently support utf-8 text only, up to 1 mib per file. attachments are sent to the configured model as part of the prompt.

conversations, memory, tool output, and preferences are stored in `~/Library/Application Support/MD3Agent/agent.sqlite`; imported files and command output files live in its `workspace` directory. the directory is private to your user, but the database is not encrypted. tool run logs can contain sensitive command output. provider credentials are stored separately in keychain.

context pruning removes complete older user turns without splitting assistant tool requests from their results. the token counter uses a conservative utf-8-byte estimate, not a model tokenizer. removed turns remain in the database. model-generated summarization and semantic memory retrieval are not yet ported.

## task panel at the notch

the native macos target shows a black task panel at the top of the display, inspired by the interaction in [ClaudeNotch](https://github.com/CraftStick/ClaudeNotch). this is an independent implementation for this application's own agent, not a claude-code hook integration. it does not copy the reference project's character or sprites.

the compact panel leaves the physical camera housing clear and shows status and elapsed time on either side. hover to see the submitted task, current tool, token counts, and stop/open-chat controls. a pending tool approval expands the panel automatically and offers allow-once and deny using the same approval continuation as the main window. completion, failure, and cancellation have distinct statuses. the timer stops when the run finishes.

the panel prefers a connected display with a physical notch and otherwise uses a virtual notch centered at the top of the main display. display geometry is recalculated when screens change. it uses a nonactivating appkit panel so hovering and approving do not take keyboard focus from the current application. no screen recording, automation, or accessibility permission is requested. turn it off with `показывать задачу у челки` in general settings. task titles and arguments are visible on the display, so disable the panel before sharing the screen if those are sensitive.

26 portable tests pass after this addition, including three geometry tests for physical notches, offset external displays, and small display bounds. swift syntax parsing passes for the new macos files. visual placement, full-screen behavior, first-click controls, and swiftui/appkit typechecking still require macos verification.
````

## `Sources/AgentCore/AgentContext.swift`

````swift
import Foundation

public actor AgentContext {
    private var messages: [ChatMessage]
    public init(messages: [ChatMessage] = []) { self.messages = messages }
    public func append(_ message: ChatMessage) { messages.append(message) }
    public func history() -> [ChatMessage] { messages }

    /// A conservative byte estimate, not a provider tokenizer or billing counter.
    public static func estimatedTokens(_ message: ChatMessage) -> Int {
        12 + message.content.utf8.count + message.toolCalls.reduce(0) {
            $0 + $1.arguments.utf8.count + $1.name.utf8.count + $1.id.utf8.count + 16
        }
    }

    public func window(systemPrompt: String, contextTokens: Int, reservedTokens: Int) throws -> [ChatMessage] {
        let system = ChatMessage(role: .system, content: systemPrompt)
        let budget = contextTokens - reservedTokens - Self.estimatedTokens(system)
        guard budget > 0 else { throw AgentError.limit("system prompt fills the context window") }
        // Remove whole user turns, never orphan tool results from their assistant calls.
        let starts = messages.indices.filter { messages[$0].role == .user }
        guard let latest = starts.last else { return [system] }
        var selected = Array(messages[latest...])
        var cost = selected.reduce(0) { $0 + Self.estimatedTokens($1) }
        guard cost <= budget else { throw AgentError.limit("latest turn exceeds the context budget; start a new conversation or shorten input") }
        for startIndex in starts.dropLast().indices.reversed() {
            let start = starts[startIndex]
            let end = starts[startIndex + 1]
            let turn = Array(messages[start..<end])
            let turnCost = turn.reduce(0) { $0 + Self.estimatedTokens($1) }
            if cost + turnCost > budget { break }
            selected.insert(contentsOf: turn, at: 0); cost += turnCost
        }
        return [system] + selected
    }
}
````

## `Sources/AgentCore/AgentEngine.swift`

````swift
import Foundation

public enum AgentEvent: Sendable {
    case message(ChatMessage)
    case draft(String)
    case usage(TokenUsage)
    case toolStarted(ToolCall)
}

public struct AgentEngine: Sendable {
    private let storage: StorageService
    public init(storage: StorageService) { self.storage = storage }

    public func run(conversation: Conversation, preferences: AppPreferences, apiKey: String,
                    approve: @escaping @Sendable (ToolCall) async -> Bool,
                    emit: @escaping @Sendable (AgentEvent) async -> Void) async throws {
        let context = AgentContext(messages: conversation.messages)
        let registry = ToolRegistry(storage: storage)
        var saved = conversation
        let rounds = min(max(preferences.maxToolRounds, 1), 64)
        let definitions = ToolRegistry.available(preferences.permissions)
        let schemaBytes = try JSONEncoder().encode(definitions).count
        for _ in 0..<rounds {
            try Task.checkCancellation()
            let messages = try await context.window(systemPrompt: preferences.systemPrompt, contextTokens: preferences.provider.contextTokens,
                                                    reservedTokens: preferences.provider.outputTokens + schemaBytes + 1024)
            var text = ""
            var calls = ToolCallAccumulator()
            var finishReason: String?
            do {
                for try await event in LLMClient().stream(configuration: preferences.provider, apiKey: apiKey, messages: messages,
                                                        tools: definitions) {
                    try Task.checkCancellation()
                    switch event {
                    case .text(let fragment):
                        text += fragment
                        guard text.utf8.count <= 4_194_304 else { throw AgentError.limit("response exceeds size limit") }
                        await emit(.draft(text))
                    case .toolDelta(let index, let id, let name, let arguments):
                        try calls.append(index: index, id: id, name: name, arguments: arguments)
                    case .usage(let usage): await emit(.usage(usage))
                    case .finished(let reason): finishReason = reason
                    }
                }
            } catch {
                if !text.isEmpty {
                    let partial = ChatMessage(role: .assistant, content: text + "\n\n[response interrupted]")
                    saved.messages.append(partial); saved.updatedAt = Date()
                    try await storage.save(saved); await emit(.message(partial))
                }
                throw error
            }
            if ["length", "max_tokens"].contains(finishReason ?? "") {
                if !text.isEmpty {
                    let partial = ChatMessage(role: .assistant, content: text + "\n\n[output token limit reached]")
                    saved.messages.append(partial); saved.updatedAt = Date()
                    try await storage.save(saved); await emit(.message(partial))
                }
                throw AgentError.limit("model reached its output limit; increase output tokens or request a shorter response")
            }
            let toolCalls = try calls.completed()
            let assistant = ChatMessage(role: .assistant, content: text, toolCalls: toolCalls)
            await context.append(assistant)
            saved.messages.append(assistant); saved.updatedAt = Date()
            // Commit tool requests and results together so interrupted runs cannot leave orphan calls on disk.
            if toolCalls.isEmpty {
                try await storage.save(saved); await emit(.message(assistant)); return
            }
            await emit(.message(assistant))
            for call in toolCalls {
                var result: String
                do {
                    try Task.checkCancellation()
                    await emit(.toolStarted(call))
                    let permission = preferences.permissions[call.name] ?? ToolRegistry.defaultPermission(for: call.name)
                    let approved = permission == .ask ? await approve(call) : false
                    try Task.checkCancellation()
                    result = try await registry.execute(call, permissions: preferences.permissions, approved: approved)
                    if result.utf8.count > 65_536 { result = String(result.prefix(16_384)) + "\n[tool output truncated]" }
                } catch { result = "tool failed: \(error.localizedDescription)" }
                let message = ChatMessage(role: .tool, content: result, toolCallID: call.id, toolName: call.name)
                await context.append(message); saved.messages.append(message)
                try await storage.appendLog(RunLog(conversationID: saved.id, tool: call.name, outcome: String(result.prefix(4096))))
                await emit(.message(message))
            }
            saved.updatedAt = Date(); try await storage.save(saved)
            try Task.checkCancellation()
        }
        throw AgentError.limit("tool round budget exhausted")
    }
}
````

````swift
public enum KeychainService {
    private static let service = "dev.huecoder.md3agent.macos"
    public static func read(account: String) throws -> String {
        var query = baseQuery(account: account)
        query[kSecReturnData as String] = true
        query[kSecMatchLimit as String] = kSecMatchLimitOne
        var result: CFTypeRef?
        let status = SecItemCopyMatching(query as CFDictionary, &result)
        if status == errSecItemNotFound { return "" }
        try validate(status)
        guard let bytes = result as? Data, let secret = String(data: bytes, encoding: .utf8) else {
            throw AgentError.storage("invalid keychain item encoding")
        }
        return secret
    }
    public static func save(_ secret: String, account: String) throws {
        if secret.isEmpty { try delete(account: account); return }
        let query = baseQuery(account: account)
        let attributes: [String: Any] = [kSecValueData as String: Data(secret.utf8),
                                         kSecAttrAccessible as String: kSecAttrAccessibleWhenUnlockedThisDeviceOnly]
        let status = SecItemUpdate(query as CFDictionary, attributes as CFDictionary)
        if status == errSecItemNotFound {
            try validate(SecItemAdd(query.merging(attributes) { _, new in new } as CFDictionary, nil))
        } else { try validate(status) }
    }
    public static func delete(account: String) throws {
        let status = SecItemDelete(baseQuery(account: account) as CFDictionary)
        if status != errSecItemNotFound { try validate(status) }
    }
    private static func baseQuery(account: String) -> [String: Any] {
        [kSecClass as String: kSecClassGenericPassword, kSecAttrService as String: service, kSecAttrAccount as String: account]
    }
    private static func validate(_ status: OSStatus) throws {
        guard status == errSecSuccess else {
            throw AgentError.storage("keychain: \(SecCopyErrorMessageString(status, nil) as String? ?? String(status))")
        }
    }
````

````swift
public struct CompletionDecoder: Sendable {
    private let kind: ProviderKind
    public private(set) var terminal = false
    public private(set) var sawFinish = false
    private var anthropicToolBlocks = Set<Int>()
    private var ollamaCallIndex = 0
    public init(kind: ProviderKind) { self.kind = kind }

    public mutating func decode(_ payload: String) throws -> [CompletionEvent] {
        if terminal { return [] }
        if payload == "[DONE]" {
            guard sawFinish else { throw AgentError.protocolViolation("done marker without finish reason") }
            terminal = true; return []
        }
        guard let bytes = payload.data(using: .utf8) else { throw AgentError.protocolViolation("invalid stream payload") }
        let root = try JSONDecoder().decode(JSONValue.self, from: bytes)
        if root["error"] != .null {
            throw AgentError.protocolViolation(root["error"]["message"].string ?? root["error"].string ?? "provider stream error")
        }
        var events: [CompletionEvent] = []
        if kind == .anthropic {
            let index = root["index"].integer ?? 0
            switch root["type"].string {
            case "content_block_start":
                let block = root["content_block"]
                if block["type"].string == "tool_use" {
                    anthropicToolBlocks.insert(index)
                    let initialInput = block["input"].object.isEmpty ? "" : try block["input"].encoded()
                    events.append(.toolDelta(index: index, id: block["id"].string, name: block["name"].string, arguments: initialInput))
                } else if let text = block["text"].string, !text.isEmpty { events.append(.text(text)) }
            case "content_block_delta":
                if let text = root["delta"]["text"].string { events.append(.text(text)) }
                if let fragment = root["delta"]["partial_json"].string, anthropicToolBlocks.contains(index) {
                    events.append(.toolDelta(index: index, id: nil, name: nil, arguments: fragment))
                }
            case "message_start":
                events.append(.usage(TokenUsage(input: root["message"]["usage"]["input_tokens"].integer ?? 0)))
            case "message_delta":
                events.append(.usage(TokenUsage(output: root["usage"]["output_tokens"].integer ?? 0)))
                if let reason = root["delta"]["stop_reason"].string { sawFinish = true; events.append(.finished(reason)) }
            case "message_stop":
                terminal = true
            default: break
            }
        } else if kind == .ollama {
            if let text = root["message"]["content"].string, !text.isEmpty { events.append(.text(text)) }
            for call in root["message"]["tool_calls"].array {
                events.append(.toolDelta(index: ollamaCallIndex, id: "ollama-\(ollamaCallIndex)", name: call["function"]["name"].string,
                                         arguments: try call["function"]["arguments"].encoded()))
                ollamaCallIndex += 1
            }
            if root["done"].boolean == true {
                events.append(.usage(TokenUsage(input: root["prompt_eval_count"].integer ?? 0, output: root["eval_count"].integer ?? 0)))
                sawFinish = true; terminal = true; events.append(.finished(root["done_reason"].string))
            }
        } else {
            if root["usage"] != .null {
                events.append(.usage(TokenUsage(input: root["usage"]["prompt_tokens"].integer ?? 0, output: root["usage"]["completion_tokens"].integer ?? 0)))
            }
            for choice in root["choices"].array where choice["index"].integer == 0 || choice["index"] == .null {
                if let text = choice["delta"]["content"].string { events.append(.text(text)) }
                for call in choice["delta"]["tool_calls"].array {
                    guard let index = call["index"].integer else { throw AgentError.protocolViolation("tool delta without index") }
                    events.append(.toolDelta(index: index, id: call["id"].string, name: call["function"]["name"].string,
                                             arguments: call["function"]["arguments"].string ?? ""))
                }
                if let reason = choice["finish_reason"].string { sawFinish = true; events.append(.finished(reason)) }
            }
        }
        return events
    }
}
````

````swift
public enum JSONValue: Codable, Sendable, Equatable {
    case string(String), number(Double), bool(Bool), object([String: JSONValue]), array([JSONValue]), null

    public init(from decoder: Decoder) throws {
        let container = try decoder.singleValueContainer()
        if container.decodeNil() { self = .null }
        else if let value = try? container.decode(Bool.self) { self = .bool(value) }
        else if let value = try? container.decode(Double.self) { self = .number(value) }
        else if let value = try? container.decode(String.self) { self = .string(value) }
        else if let value = try? container.decode([String: JSONValue].self) { self = .object(value) }
        else { self = .array(try container.decode([JSONValue].self)) }
    }

    public func encode(to encoder: Encoder) throws {
        var container = encoder.singleValueContainer()
        switch self {
        case .string(let value): try container.encode(value)
        case .number(let value): try container.encode(value)
        case .bool(let value): try container.encode(value)
        case .object(let value): try container.encode(value)
        case .array(let value): try container.encode(value)
        case .null: try container.encodeNil()
        }
    }
````

````swift
public struct ProcessResult: Codable, Sendable {
    public var exitCode: Int32
    public var stdout: String
    public var stderr: String

    public var truncated: Bool

private final class CancellationFlag: @unchecked Sendable {
    private let lock = NSLock()
    private var value = false
    func cancel() { lock.lock(); value = true; lock.unlock() }
    var cancelled: Bool { lock.lock(); defer { lock.unlock() }; return value }
}

public enum ProcessRunner {
    public static func run(executable: URL, arguments: [String], directory: URL, input: String = "",
                           timeout: TimeInterval = 60, maximumOutputBytes: Int = 1_048_576) async throws -> ProcessResult {
        guard timeout > 0, timeout <= 600, maximumOutputBytes > 0, input.utf8.count <= 1_048_576 else {
            throw AgentError.limit("invalid process limits")
        }
        let cancellation = CancellationFlag()
        return try await withTaskCancellationHandler {
            try await Task.detached(priority: .userInitiated) {
                if cancellation.cancelled { throw CancellationError() }
                let process = Process()
                let outputPipe = Pipe(), errorPipe = Pipe()
                // Use a file for stdin so a child that never reads cannot block its parent.
                let inputURL = FileManager.default.temporaryDirectory.appendingPathComponent(UUID().uuidString)
                try Data(input.utf8).write(to: inputURL, options: .atomic)
                try FileManager.default.setAttributes([.posixPermissions: 0o600], ofItemAtPath: inputURL.path)
                defer { try? FileManager.default.removeItem(at: inputURL) }
                let inputHandle = try FileHandle(forReadingFrom: inputURL)
                defer { try? inputHandle.close() }
                process.executableURL = executable
                process.arguments = arguments
                process.currentDirectoryURL = directory
                process.environment = ["PATH": "/opt/homebrew/bin:/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin",
                                       "HOME": FileManager.default.homeDirectoryForCurrentUser.path,
                                       "LANG": "en_US.UTF-8", "TMPDIR": FileManager.default.temporaryDirectory.path]
                process.standardInput = inputHandle
                process.standardOutput = outputPipe
                process.standardError = errorPipe
                try process.run()
                try outputPipe.fileHandleForWriting.close()
                try errorPipe.fileHandleForWriting.close()
                let outputFD = outputPipe.fileHandleForReading.fileDescriptor
                let errorFD = errorPipe.fileHandleForReading.fileDescriptor
                defer {
                    try? outputPipe.fileHandleForReading.close()
                    try? errorPipe.fileHandleForReading.close()
                }
                _ = fcntl(outputFD, F_SETFL, O_NONBLOCK)
                _ = fcntl(errorFD, F_SETFL, O_NONBLOCK)
                let started = ProcessInfo.processInfo.systemUptime
                var stopTime: TimeInterval?
                var timedOut = false
                var stdout = Data(), stderr = Data()
                var truncated = false
                var buffer = [UInt8](repeating: 0, count: 16_384)
                func drain(_ fd: Int32, into captured: inout Data) {
                    // Limit work per poll as well as retained bytes, even for a noisy child.
                    for _ in 0..<16 {
                        let count = read(fd, &buffer, buffer.count)
                        if count <= 0 { break }
                        let room = max(0, maximumOutputBytes - captured.count)
                        captured.append(contentsOf: buffer.prefix(min(count, room)))
                        if count > room { truncated = true }
                    }
                }
                while process.isRunning {
                    drain(outputFD, into: &stdout); drain(errorFD, into: &stderr)
                    let now = ProcessInfo.processInfo.systemUptime
                    if stopTime == nil && (cancellation.cancelled || now - started >= timeout) {
                        timedOut = !cancellation.cancelled
                        stopTime = now
                        process.terminate()
                    }
                    if let stopTime, now - stopTime >= 1 { _ = kill(process.processIdentifier, SIGKILL) }
                    usleep(10_000)
                }
                process.waitUntilExit()
                drain(outputFD, into: &stdout); drain(errorFD, into: &stderr)
                if cancellation.cancelled { throw CancellationError() }
                return ProcessResult(exitCode: process.terminationStatus, stdout: String(decoding: stdout, as: UTF8.self),
                                     stderr: String(decoding: stderr, as: UTF8.self), timedOut: timedOut, truncated: truncated)
            }.value
        } onCancel: { cancellation.cancel() }
    }
}
````

````swift
    private func statement(_ sql: String, values: [Binding]) throws -> OpaquePointer {
        var prepared: OpaquePointer?
        guard sqlite3_prepare_v2(connection.pointer, sql, -1, &prepared, nil) == SQLITE_OK, let prepared else {
            throw databaseError()
        }
        do {
            for (offset, binding) in values.enumerated() {
                let index = Int32(offset + 1)
                let transient = unsafeBitCast(-1, to: sqlite3_destructor_type.self)
                let status: Int32
                switch binding {
                case .text(let value): status = value.withCString { sqlite3_bind_text(prepared, index, $0, -1, transient) }
                case .real(let value): status = sqlite3_bind_double(prepared, index, value)
                case .blob(let value): status = value.withUnsafeBytes { sqlite3_bind_blob(prepared, index, $0.baseAddress, Int32($0.count), transient) }
                }
                guard status == SQLITE_OK else { throw databaseError() }
            }
            return prepared
        } catch { sqlite3_finalize(prepared); throw error }
    }
    private func execute(_ sql: String, values: [Binding]) throws {
        let prepared = try statement(sql, values: values)
        defer { sqlite3_finalize(prepared) }
        guard sqlite3_step(prepared) == SQLITE_DONE else { throw databaseError() }
    }
    private func query<T: Decodable>(_ sql: String, values: [Binding], as type: T.Type) throws -> [T] {
        let prepared = try statement(sql, values: values)
        defer { sqlite3_finalize(prepared) }
        var decoded: [T] = []
        while true {
            let status = sqlite3_step(prepared)
            if status == SQLITE_DONE { return decoded }
            guard status == SQLITE_ROW, let pointer = sqlite3_column_blob(prepared, 0) else { throw databaseError() }
            let bytes = Data(bytes: pointer, count: Int(sqlite3_column_bytes(prepared, 0)))
            decoded.append(try JSONDecoder().decode(type, from: bytes))
        }
    }
    private func databaseError() -> AgentError {
        .storage(String(cString: sqlite3_errmsg(connection.pointer)))
    }
}
````

````swift
import Foundation

/// Keeps bytes intact until a complete line arrives, including split UTF-8 scalars.
public struct StreamParser: Sendable {
    public enum Format: Sendable { case sse, jsonLines }
    private let format: Format
    private let maximumBytes: Int
    private var lineBytes = Data()
    private var eventLines: [String] = []
    private var eventBytes = 0
    private var previousWasCR = false
    private var firstLine = true

    public init(format: Format = .sse, maximumBytes: Int = 1_048_576) {
        self.format = format; self.maximumBytes = maximumBytes
    }

    public mutating func append(_ bytes: Data) throws -> [String] {
        var payloads: [String] = []
        for byte in bytes {
            if byte == 10 && previousWasCR { previousWasCR = false; continue }
            previousWasCR = byte == 13
            if byte == 10 || byte == 13 {
                try consumeLine(into: &payloads)
            } else {
                lineBytes.append(byte)
                guard lineBytes.count + eventBytes <= maximumBytes else {
                    throw AgentError.limit("stream event exceeds byte limit")
                }
            }
        }
        return payloads
    }

    public mutating func finish() throws -> [String] {
        var payloads: [String] = []
        if !lineBytes.isEmpty { try consumeLine(into: &payloads) }
        dispatch(into: &payloads)
        return payloads
    }

    private mutating func consumeLine(into payloads: inout [String]) throws {
        guard var line = String(data: lineBytes, encoding: .utf8) else {
            throw AgentError.protocolViolation("invalid utf-8 in stream")
        }
        if firstLine {
            if line.hasPrefix("\u{feff}") { line.removeFirst() }
            firstLine = false
        }
        lineBytes.removeAll(keepingCapacity: true)
        switch format {
        case .jsonLines:
            if !line.trimmingCharacters(in: .whitespaces).isEmpty { payloads.append(line) }
        case .sse:
            if line.isEmpty { dispatch(into: &payloads) }
            else if line.hasPrefix("data:") {
                var value = String(line.dropFirst(5))
                if value.hasPrefix(" ") { value.removeFirst() }
                eventBytes += value.utf8.count + 1
                guard eventBytes <= maximumBytes else { throw AgentError.limit("stream event exceeds byte limit") }
                eventLines.append(value)
            }
        }
    }

    private mutating func dispatch(into payloads: inout [String]) {
        if !eventLines.isEmpty { payloads.append(eventLines.joined(separator: "\n")) }
        eventLines.removeAll(keepingCapacity: true); eventBytes = 0
    }
}

public struct ToolCallAccumulator: Sendable {
    private var calls: [Int: ToolCall] = [:]
    public init() {}
    public mutating func append(index: Int, id: String?, name: String?, arguments: String) throws {
        guard index >= 0, index < 128 else { throw AgentError.limit("too many tool calls") }
        var call = calls[index] ?? ToolCall(id: "", name: "", arguments: "")
        if let id, !id.isEmpty { call.id = id }
        if let name, !name.isEmpty { call.name += name }
        call.arguments += arguments
        guard call.arguments.utf8.count <= 1_048_576 else { throw AgentError.limit("tool arguments exceed byte limit") }
        calls[index] = call
    }
    public func completed() throws -> [ToolCall] {
        let ordered = calls.keys.sorted().compactMap { calls[$0] }.map { call in
            var completed = call
            // Anthropic can finish an empty-input tool without a JSON delta.
            if completed.arguments.isEmpty { completed.arguments = "{}" }
            return completed
        }
        guard Set(ordered.map(\.id)).count == ordered.count else {
            throw AgentError.protocolViolation("duplicate tool call ids")
        }
        for call in ordered {
            guard !call.id.isEmpty, !call.name.isEmpty,
                  case .object = try JSONDecoder().decode(JSONValue.self, from: Data(call.arguments.utf8)) else {
                throw AgentError.protocolViolation("incomplete tool call")
            }
        }
        return ordered
    }
}
````

````swift
public struct ToolRegistry: Sendable {
    public let storage: StorageService
    public init(storage: StorageService) { self.storage = storage }

    public static let definitions: [ToolDefinition] = [
        definition("list_files", "List files inside the workspace.", ["path": "string"], required: []),
        definition("read_file", "Read a UTF-8 file inside the workspace, at most 1 MiB.", ["path": "string"]),

        definition("list_chats", "List conversation ids and titles.", [:]),
        definition("read_chat", "Read a saved conversation by UUID.", ["id": "string"]),
        definition("search_messages", "Search saved chat messages.", ["query": "string"])

    public static func defaultPermission(for name: String) -> ToolPermission {

        case "run_command", "run_python": .off
        default: .ask
        }
    }

    public static func available(_ permissions: [String: ToolPermission]) -> [ToolDefinition] {
        definitions.filter { (permissions[$0.name] ?? defaultPermission(for: $0.name)) != .off }
    }

    public func execute(_ call: ToolCall, permissions: [String: ToolPermission], approved: Bool) async throws -> String {
        guard let definition = Self.definitions.first(where: { $0.name == call.name }) else {
            throw AgentError.denied("unknown tool")
        }
        let permission = permissions[call.name] ?? Self.defaultPermission(for: call.name)
        guard permission != .off, permission != .ask || approved else { throw AgentError.denied("tool execution denied") }
        let root = try JSONDecoder().decode(JSONValue.self, from: Data(call.arguments.utf8))
        guard case .object(let arguments) = root else { throw AgentError.protocolViolation("tool arguments must be an object") }
        let properties = definition.parameters["properties"].object
        guard Set(arguments.keys).isSubset(of: Set(properties.keys)) else { throw AgentError.protocolViolation("unexpected tool argument") }
        for required in definition.parameters["required"].array.compactMap(\.string) {
            guard arguments[required]?.string != nil else { throw AgentError.protocolViolation("missing string argument: \(required)") }
        }
        for (name, value) in arguments where value.string == nil {
            throw AgentError.protocolViolation("argument must be a string: \(name)")
        }
        func string(_ key: String) -> String { arguments[key]?.string ?? "" }
        switch call.name {
        case "list_files":
            let directory = try workspaceURL(string("path"))
            let files = try FileManager.default.contentsOfDirectory(at: directory, includingPropertiesForKeys: [.isDirectoryKey])
            guard files.count <= 10_000 else { throw AgentError.limit("directory has too many entries") }
            return files.map(\.lastPathComponent).sorted().joined(separator: "\n")
        case "read_file":
            let url = try workspaceURL(string("path"))
            let handle = try FileHandle(forReadingFrom: url)
            defer { try? handle.close() }
            let bytes = try handle.read(upToCount: 1_048_577) ?? Data()
            guard bytes.count <= 1_048_576, let text = String(data: bytes, encoding: .utf8) else {
                throw AgentError.limit("file is too large or not utf-8")
            }
            return text
        case "write_file":
            let url = try workspaceURL(string("path"))
            guard string("content").utf8.count <= 1_048_576 else { throw AgentError.limit("file content too large") }
            try Data(string("content").utf8).write(to: url, options: .atomic)
            return "wrote \(string("content").utf8.count) bytes"
        case "run_command", "run_python":
            let isPython = call.name == "run_python"
            let result = try await ProcessRunner.run(executable: URL(fileURLWithPath: isPython ? "/usr/bin/env" : "/bin/zsh"),
                                                     arguments: isPython ? ["python3", "-c", string("code")] : ["-c", string("command")], directory: storage.workspace)
            return String(decoding: try JSONEncoder().encode(result), as: UTF8.self)
        case "memory_add":
            let memory = MemoryRecord(title: string("title"), content: string("content"))
            try await storage.saveMemory(memory)
            return memory.id.uuidString
        case "memory_list", "memory_search":
            let words = string("query").lowercased().split(whereSeparator: \.isWhitespace)
            let memories = try await storage.memories().filter { memory in
                let text = (memory.title + " " + memory.content).lowercased()
                return words.allSatisfy { text.contains($0) }
            }
            return String(decoding: try JSONEncoder().encode(memories), as: UTF8.self)
        case "memory_delete":
            guard let id = UUID(uuidString: string("id")) else { throw AgentError.protocolViolation("invalid memory id") }
            try await storage.deleteMemory(id); return "memory deleted"
        case "list_chats":
            return try await storage.conversations().map { "\($0.id.uuidString) \($0.title)" }.joined(separator: "\n")
        case "read_chat":
            guard let id = UUID(uuidString: string("id")), let chat = try await storage.conversations().first(where: { $0.id == id }) else {
                throw AgentError.protocolViolation("conversation not found")
            }
            return String(decoding: try JSONEncoder().encode(chat), as: UTF8.self)
        case "search_messages":
            let query = string("query")
            guard !query.isEmpty else { throw AgentError.protocolViolation("empty search query") }
            return try await storage.conversations().flatMap { chat in
                chat.messages.filter { $0.content.localizedCaseInsensitiveContains(query) }.map { "\(chat.id): \($0.role.rawValue): \($0.content.prefix(2000))" }
            }.prefix(100).joined(separator: "\n")
        default: throw AgentError.denied("tool is not executable")
        }
    }

    private func workspaceURL(_ path: String) throws -> URL {
        guard !path.hasPrefix("/"), !path.contains("\0") else { throw AgentError.denied("workspace paths must be relative") }
        let root = storage.workspace.resolvingSymlinksInPath().standardizedFileURL
        let target = root.appendingPathComponent(path).resolvingSymlinksInPath().standardizedFileURL
        guard target.path == root.path || target.path.hasPrefix(root.path + "/") else {
            throw AgentError.denied("path escapes workspace")
        }
        return target
    }

    private static func definition(_ name: String, _ description: String, _ fields: [String: String], required: [String]? = nil) -> ToolDefinition {
        ToolDefinition(name: name, description: description, parameters: .object([
            "type": .string("object"), "properties": .object(fields.mapValues { .object(["type": .string($0)]) }),
            "required": .array((required ?? fields.keys.sorted()).map(JSONValue.string)), "additionalProperties": .bool(false)
        ]))
    }
}
````

````swift
@MainActor @Observable
final class AppModel {
    enum RunOutcome { case idle, completed, failed, stopped }
    var runOutcome: RunOutcome = .idle
    var runTitle: String?
    var runStartedAt: Date?
    var runFinishedAt: Date?

    var draft = ""
    var streamedText = ""

    var isRunning = false
    var usage = TokenUsage()
    var pendingApproval: ToolCall?
    var activeTool: String?
    var storage: StorageService?
    private var execution: Task<Void, Never>?
    private var approvalContinuation: CheckedContinuation<Bool, Never>?
    private var initialized = false

    var selectedConversation: Conversation? { conversations.first { $0.id == selectedID } }

    func initialize() async {
        guard !initialized else { return }
        initialized = true
        do {
            let database = try StorageService()
            storage = database
            conversations = try await database.conversations()
            preferences = try await database.preferences()
            selectedID = conversations.first?.id
        } catch { errorMessage = error.localizedDescription }
    }

    func newConversation() {
        guard !isRunning else { return }
        let conversation = Conversation()
        conversations.insert(conversation, at: 0); selectedID = conversation.id
        draft = ""; streamedText = ""; errorMessage = nil
    }

    func deleteSelected() async {
        guard !isRunning, let id = selectedID, let storage else { return }
        do {
            try await storage.deleteConversation(id)
            conversations.removeAll { $0.id == id }; selectedID = conversations.first?.id
        } catch { errorMessage = error.localizedDescription }
    }

    func savePreferences() async {
        guard let storage else { return }
        do { try await storage.savePreferences(preferences) }
        catch { errorMessage = error.localizedDescription }
    }

    func send() {
        guard !isRunning, !draft.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty, let storage else { return }
        let submittedText = draft.trimmingCharacters(in: .whitespacesAndNewlines)
        if selectedID == nil { newConversation() }
        guard let index = conversations.firstIndex(where: { $0.id == selectedID }) else { return }
        let user = ChatMessage(role: .user, content: submittedText)
        conversations[index].messages.append(user)
        if conversations[index].messages.count == 1 { conversations[index].title = String(user.content.prefix(60)) }
        conversations[index].updatedAt = Date()
        let conversation = conversations[index]
        let configuration = preferences
        draft = ""; streamedText = ""; errorMessage = nil; isRunning = true
        runTitle = String(submittedText.prefix(160)); runStartedAt = Date(); runFinishedAt = nil
        runOutcome = .idle; usage = TokenUsage(); activeTool = nil
        execution = Task {
            defer { isRunning = false; runFinishedAt = Date(); execution = nil; streamedText = ""; activeTool = nil; resolveApproval(false) }
            do {
                try await storage.save(conversation)
                let endpoint = try configuration.provider.validatedURL()
                let account = "\(configuration.provider.kind.rawValue):\(endpoint.absoluteString)"
                let apiKey = try KeychainService.read(account: account)
                try await AgentEngine(storage: storage).run(conversation: conversation, preferences: configuration, apiKey: apiKey,
                    approve: { [weak self] call in await self?.requestApproval(call) ?? false },
                    emit: { [weak self] event in await self?.receive(event, conversationID: conversation.id) })
                runOutcome = .completed
            } catch is CancellationError {
                runOutcome = .stopped
                errorMessage = "response stopped"
            } catch { runOutcome = .failed; errorMessage = error.localizedDescription }
            do {
                conversations = try await storage.conversations()
            } catch { errorMessage = "could not reload conversations: \(error.localizedDescription)" }
        }
    }

    func stop() { execution?.cancel(); resolveApproval(false) }

    private func receive(_ event: AgentEvent, conversationID: UUID) {
        switch event {
        case .draft(let text): streamedText = text; activeTool = nil
        case .message(let message):
            if let index = conversations.firstIndex(where: { $0.id == conversationID }) {
                conversations[index].messages.append(message)
            }
            streamedText = ""
            if message.role == .tool { activeTool = nil }
        case .usage(let received):
            if received.input > 0 { usage.input = received.input }
            if received.output > 0 { usage.output = received.output }
        case .toolStarted(let call): activeTool = call.name
        }
    }

    private func requestApproval(_ call: ToolCall) async -> Bool {
        if Task.isCancelled { return false }
        return await withCheckedContinuation { continuation in
            approvalContinuation = continuation; pendingApproval = call
        }
    }

    func resolveApproval(_ approved: Bool) {
        let continuation = approvalContinuation
        approvalContinuation = nil; pendingApproval = nil
        continuation?.resume(returning: approved)
    }

    func importFiles(_ urls: [URL]) async {
        guard !isRunning, let storage else { return }
        for url in urls {
            let granted = url.startAccessingSecurityScopedResource()
            defer { if granted { url.stopAccessingSecurityScopedResource() } }
            do {
                let values = try url.resourceValues(forKeys: [.isRegularFileKey, .fileSizeKey])
                guard values.isRegularFile == true, (values.fileSize ?? Int.max) <= 1_048_576 else {
                    throw AgentError.limit("attachments must be regular files up to 1 mib")
                }
                let bytes = try Data(contentsOf: url)
                guard let text = String(data: bytes, encoding: .utf8) else {
                    throw AgentError.invalidConfiguration("only utf-8 text attachments are supported by this native target")
                }
                let name = UUID().uuidString + "-" + url.lastPathComponent
                try bytes.write(to: storage.workspace.appendingPathComponent(name), options: .atomic)
                draft += "\n\n<attachment name=\(name)>\n\(text)\n</attachment>"
            } catch { errorMessage = "\(url.lastPathComponent): \(error.localizedDescription)" }
        }
    }
}
````

private struct MarkdownContent: View {
    let text: String

        var result: [MarkdownBlock] = []
        var lines: [String] = []
        var language: String?
        for line in text.components(separatedBy: "\n") {
            if line.hasPrefix("```") {
                if !lines.isEmpty {
                    result.append(MarkdownBlock(id: result.count, text: lines.joined(separator: "\n"), language: language))
                    lines = []
                }
                if language != nil { language = nil }
                else { language = String(line.dropFirst(3)).trimmingCharacters(in: .whitespaces) }
            } else { lines.append(line) }
        }
        if !lines.isEmpty { result.append(MarkdownBlock(id: result.count, text: lines.joined(separator: "\n"), language: language)) }
        return result
    }
    var body: some View {
        ForEach(blocks) { block in
            if let language = block.language {
                VStack(alignment: .leading, spacing: 8) {
                    HStack {
                        Text(language.isEmpty ? "code" : language).foregroundStyle(.secondary)

````swift
import Carbon
import Foundation
import AgentCore

// Only HotkeyManager mutates registration on the main actor. The owner makes
// cleanup independent of the executor on which Swift releases the last reference.
private final class HotkeyRegistration: @unchecked Sendable {
    var hotkey: EventHotKeyRef?
    var handler: EventHandlerRef?
    func clear() {
        if let hotkey { UnregisterEventHotKey(hotkey); self.hotkey = nil }
        if let handler { RemoveEventHandler(handler); self.handler = nil }
    }
    deinit { clear() }
}

@MainActor
final class HotkeyManager {
    private let registration = HotkeyRegistration()
    private var action: (@MainActor () -> Void)?

    func configure(enabled: Bool, action: @escaping @MainActor () -> Void) throws {
        registration.clear()
        self.action = action
        guard enabled else { return }
        var eventType = EventTypeSpec(eventClass: OSType(kEventClassKeyboard), eventKind: UInt32(kEventHotKeyPressed))
        let context = Unmanaged.passUnretained(self).toOpaque()
        let status = InstallEventHandler(GetApplicationEventTarget(), { _, _, context in
            guard let context else { return OSStatus(eventNotHandledErr) }
            // Carbon dispatches application events on the main thread.
            MainActor.assumeIsolated {
                Unmanaged<HotkeyManager>.fromOpaque(context).takeUnretainedValue().action?()
            }
            return noErr
        }, 1, &eventType, context, &registration.handler)
        guard status == noErr else { throw AgentError.invalidConfiguration("could not install global shortcut handler: \(status)") }
        let keyID = EventHotKeyID(signature: 0x4d443341, id: 1)
        let registrationStatus = RegisterEventHotKey(UInt32(kVK_Space), UInt32(controlKey | optionKey), keyID,
                                               GetApplicationEventTarget(), 0, &self.registration.hotkey)
        guard registrationStatus == noErr else {
            self.registration.clear()
            throw AgentError.invalidConfiguration("global shortcut is unavailable: \(registrationStatus)")
        }
    }
}
````

````swift
    required init?(coder: NSCoder) { fatalError("init(coder:) is unavailable") }

    func update(model: AppModel, enabled: Bool, openConversation: @escaping @MainActor () -> Void) {

        self.enabled = enabled
        self.openConversation = openConversation
        if !enabled { hovered = false; window?.orderOut(nil); return }
        layout()
        window?.orderFrontRegardless()
    }

    @objc private func screenChanged() { if enabled { layout() } }

        guard let model, let window,
              let screen = NSScreen.screens.first(where: { $0.safeAreaInsets.top > 0 }) ?? NSScreen.main ?? NSScreen.screens.first else { return }
        let expanded = hovered || model.pendingApproval != nil
        let geometry = NotchLayout(screen: screen.frame, topInset: screen.safeAreaInsets.top,
                                   leftArea: screen.auxiliaryTopLeftArea, rightArea: screen.auxiliaryTopRightArea, expanded: expanded)
        window.setFrame(geometry.frame, display: true)
        let content = NotchTaskView(model: model, expanded: expanded, cameraWidth: geometry.cameraWidth,
                                    headerHeight: geometry.headerHeight, openConversation: { [weak self] in self?.openConversation?() },
                                    hoverChanged: { [weak self] hovering in
            guard let self, hovered != hovering else { return }
            hovered = hovering
            layout()
        })
        if let hosting = window.contentView as? NotchHostingView<NotchTaskView> {
            hosting.rootView = content
        } else { window.contentView = NotchHostingView(rootView: content) }
    }
}
````

````swift
        try check(try await storage.preferences() == preferences, "preferences round trip")
        let memory = MemoryRecord(title: "note", content: "remember")
        try await storage.saveMemory(memory)
        try check(try await storage.memories() == [memory], "memory round trip")
        try await storage.deleteMemory(memory.id)
        try check(try await storage.memories().isEmpty, "memory deletion")
        try await storage.appendLog(RunLog(conversationID: chat.id, tool: "read_file", outcome: "ok"))
        try check(try await storage.logs(conversationID: chat.id).count == 1, "run logs")
        try await storage.deleteConversation(chat.id)
        try check(try await storage.conversations().isEmpty, "conversation deletion")
        try check(try await storage.logs(conversationID: chat.id).isEmpty, "transactional log deletion")
        let registry = ToolRegistry(storage: storage)
        let fileCall = ToolCall(id: "file", name: "write_file", arguments: "{\"path\":\"note.txt\",\"content\":\"saved text\"}")
        _ = try await registry.execute(fileCall, permissions: [:], approved: true)
        let readCall = ToolCall(id: "read", name: "read_file", arguments: "{\"path\":\"note.txt\"}")
        try check(try await registry.execute(readCall, permissions: [:], approved: true) == "saved text", "workspace file round trip")
        do {
            _ = try await registry.execute(ToolCall(id: "escape", name: "read_file", arguments: "{\"path\":\"../agent.sqlite\"}"), permissions: [:], approved: true)
            throw AgentError.protocolViolation("path traversal was allowed")
        } catch AgentError.denied { checks += 1 }
        do {
            _ = try await registry.execute(readCall, permissions: [:], approved: false)
            throw AgentError.protocolViolation("unapproved call was allowed")
        } catch AgentError.denied { checks += 1 }
        let process = try await ProcessRunner.run(executable: URL(fileURLWithPath: "/bin/sh"),
                                                  arguments: ["-c", "printf output; printf error >&2"], directory: root)
        try check(process.stdout == "output" && process.stderr == "error" && process.exitCode == 0, "process pipes")
        let timeout = try await ProcessRunner.run(executable: URL(fileURLWithPath: "/bin/sleep"), arguments: ["10"], directory: root, timeout: 0.05)
        try check(timeout.timedOut, "process timeout")
        let bounded = try await ProcessRunner.run(executable: URL(fileURLWithPath: "/bin/sh"),
                                                  arguments: ["-c", "printf 1234567890"], directory: root, maximumOutputBytes: 4)
        try check(bounded.stdout == "1234" && bounded.truncated, "bounded output")
        print("passed \(checks) portable checks")
    }
}
````

## `scripts/export-native-source.py`

````python
#!/usr/bin/env python3
"""Generate a complete, path-labelled native source bundle for review."""
from pathlib import Path


def main() -> None:
    root = Path(__file__).resolve().parents[1]
    explicit = ["Package.swift", "Info.plist", "MD3Agent.entitlements", "README.md",
                "docs/macos-port.md", "scripts/package-macos.sh",
                "scripts/VerifyPortable.swift", "scripts/export-native-source.py"]
    paths = [root / name for name in explicit]
    for directory in ["Sources", "Tests", ".github/workflows"]:
        paths.extend(path for path in (root / directory).rglob("*") if path.is_file())
    suffix_languages = {".swift": "swift", ".plist": "xml", ".entitlements": "xml",
                        ".h": "c", ".yml": "yaml", ".sh": "bash", ".py": "python",
                        ".md": "markdown"}
    sections = ["# native source bundle\n\n"
                "generated by `python3 scripts/export-native-source.py`. "
                "complete files follow; no source content is abbreviated.\n"]
    for path in sorted(set(paths)):
        content = path.read_text(encoding="utf-8")
        longest = max((len(part) for part in content.split("\n") if part and set(part) == {"`"}), default=0)
        fence = "`" * max(4, longest + 1)
        language = suffix_languages.get(path.suffix, "text")
        sections.append(f"\n## `{path.relative_to(root)}`\n\n{fence}{language}\n{content.rstrip()}\n{fence}\n")
    destination = root / "docs/native-source.md"
    destination.write_text("".join(sections), encoding="utf-8")
    print(f"exported {len(set(paths))} complete files to {destination.relative_to(root)}")


if __name__ == "__main__":
    main()
````

## `scripts/package-macos.sh`

````bash
#!/bin/bash
set -euo pipefail

configuration="${CONFIGURATION:-release}"
architecture="${ARCHITECTURE:-arm64}"
version="${VERSION:-0.1.0}"
destination="${OUTPUT_DIRECTORY:-dist}"
identity="${SIGNING_IDENTITY:--}"

if [[ "$(uname -s)" != Darwin ]]; then
    printf '%s\n' 'macos is required to package this application' >&2
    exit 1
fi
if [[ ! "$version" =~ ^[0-9]+\.[0-9]+\.[0-9]+([.-][A-Za-z0-9.-]+)?$ ]]; then
    printf '%s\n' 'VERSION must be a semantic version' >&2
    exit 1
fi
if [[ "$architecture" != arm64 && "$architecture" != x86_64 ]]; then
    printf '%s\n' 'ARCHITECTURE must be arm64 or x86_64' >&2
    exit 1
fi

swift build -c "$configuration" --arch "$architecture"
binary_directory="$(swift build -c "$configuration" --arch "$architecture" --show-bin-path)"
application="$destination/MD3Agent.app"
mkdir -p "$application/Contents/MacOS" "$application/Contents/Resources"
install -m 755 "$binary_directory/MD3Agent" "$application/Contents/MacOS/MD3Agent"
install -m 644 Info.plist "$application/Contents/Info.plist"
install -m 644 LICENSE "$application/Contents/Resources/LICENSE"
/usr/libexec/PlistBuddy -c "Set :CFBundleShortVersionString $version" "$application/Contents/Info.plist"
/usr/libexec/PlistBuddy -c "Set :CFBundleVersion ${BUILD_NUMBER:-1}" "$application/Contents/Info.plist"

if [[ "$identity" == - ]]; then
    codesign --force --sign - --entitlements MD3Agent.entitlements "$application"
else
    codesign --force --options runtime --timestamp --sign "$identity" --entitlements MD3Agent.entitlements "$application"
fi
codesign --verify --strict --verbose=2 "$application"
printf '%s\n' "$application"
````
